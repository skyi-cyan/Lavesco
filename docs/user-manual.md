# Lavesco 사용 매뉴얼

골프 라운드 스코어를 기록하고 동반자와 공유하는 **Lavesco(라베스코)** 모바일 앱 안내입니다. 화면 이름과 동작은 현재 앱(`mobile-rn`, Android 1.0.16) 기준입니다.

---

## 1. 앱 소개

- **무엇을 하나요?** 골프장·코스를 선택해 라운드를 만들거나, 6자리 번호로 참여한 뒤 홀별 스코어를 입력합니다. 동반자는 각자 본인 스코어만 입력하고, 조원 전체의 스코어는 한 스코어카드에서 함께 봅니다.
- **그 밖의 기능:** 나의 기록·통계, 골프장·코스 정보, GPS 클럽 거리기록, 코스 추가 요청
- **플랫폼:** Android (Google Play). iOS는 준비 중입니다.
- **지원 언어:** 한국어, English, 日本語

---

## 2. 시작하기

### 2.1 계정 만들기·로그인

1. 앱을 실행하면 **로그인** 화면이 나옵니다.
2. **이메일**과 **비밀번호**로 로그인하거나, 화면 하단 **회원가입**으로 새 계정을 만듭니다.
3. 회원가입에서는 이메일, 비밀번호(6자 이상), 닉네임, **기본 티**(Black·Blue·White·Red)를 입력하고, 필수 약관(서비스 이용약관, 개인정보 처리방침)에 동의합니다. 마케팅 수신 동의는 선택입니다.
4. **iOS**에서는 **Apple로 로그인**과 **Google로 로그인**을 사용할 수 있습니다. Android에서는 현재 이메일 로그인만 제공합니다.

### 2.2 언어

- 처음 실행하면 휴대폰 언어에 맞춰 한국어·일본어가 자동 선택되고, 그 밖의 언어는 영어로 시작합니다.
- **MY → 설정 → 언어**에서 언제든 바꿀 수 있으며, 고른 언어는 다음 실행에도 유지됩니다.

### 2.3 화면 구성 (하단 탭 5개)

| 탭 | 이름 | 주요 기능 |
|----|------|-----------|
| 1 | **홈** | 나의 요약 기록, 라운드 만들기·참여하기, 코스 추가 요청 |
| 2 | **라운드** | 연도별 라운드 목록, 스코어 입력, 라운드 취소 |
| 3 | **거리** | GPS 클럽 거리기록, 클럽별 거리 통계 |
| 4 | **코스** | 골프장 검색·권역 필터, 코스·홀 정보 조회 |
| 5 | **MY** | 프로필, 나의 기록 표, 설정(프로필 수정·알림·언어), 로그아웃 |

## 3. 홈 탭

- 상단 이미지에 **「(닉네임)님의 기록」** 이 표시됩니다.
- **기록 카드** (확정된 라운드 기준)
  - **라운드수 / 베스트(최소 타수) / 평균 타수**
  - **FW 안착율(FIR), 그린 적중율(GIR), 평균퍼팅수(PPR)**
- 화면 하단 고정 버튼
  - **라운드 만들기:** 라운드 생성 화면으로 이동합니다.
  - **참여하기:** 라운드 번호로 참여하는 화면으로 이동합니다.
  - **코스추가 요청하기:** 목록에 없는 골프장 등록을 요청합니다. ([10장](#10-코스-추가-요청) 참고)

---

## 4. 라운드 만들기

**경로:** 홈 →「라운드 만들기」

1. **라운드(대회)명**을 입력합니다. (선택)
2. **골프장**을 이름·지역으로 검색해 선택합니다. 목록에 없으면 **직접입력**을 체크하고 이름을 입력합니다.
3. **전반코스**와 **후반코스**를 선택합니다. 후반코스는 전반코스를 고른 뒤 선택할 수 있습니다. 직접입력한 골프장은 코스 이름을 직접 입력합니다. (선택)
4. **날짜**(기본값: 오늘)와 **티타임**(1부/2부/3부)을 고릅니다.
5. **완료**를 누르면 라운드가 생성되고 **6자리 라운드 번호**가 안내됩니다. 이 번호를 동반자에게 알려 주세요.

---

## 5. 라운드 참여하기

**경로:** 홈 →「참여하기」

1. 호스트가 알려 준 **6자리 라운드 번호**를 입력합니다. (이전에 만든 라운드는 4자리일 수 있습니다.)
2. **검색**을 누르면 골프장, 날짜, 티타임, 상태(준비·진행 중·종료)가 표시됩니다.
3. **참여하기**를 누르면 참여가 완료됩니다. 이미 참여한 라운드라면 **라운드 보기**로 바로 이동할 수 있습니다.

---

## 6. 라운드 탭 (목록)

- 상단의 **연도**(예: 2026년)를 눌러 해당 연도의 라운드만 볼 수 있습니다.
- 목록을 아래로 당기면 **새로고침**됩니다.
- 카드를 누르면 해당 라운드의 **스코어 등록** 화면으로 들어갑니다.
- 카드에는 라운드명(또는 코스명), 골프장, 날짜가 표시됩니다.
  - 확정 전: **#라운드번호**와 상태(**준비** / **진행중**)
  - 확정 후: 나의 **총타수**
- **라운드 취소:** 내가 만든 라운드이고 스코어를 확정하기 전이면, 카드를 **길게 눌러** 취소할 수 있습니다. 취소하면 참가자·스코어·라운드 번호가 모두 삭제됩니다.
- 새 라운드 만들기와 참여하기는 **홈** 화면에서 합니다.

---

## 7. 스코어 등록 (라운드 상세)

화면 제목은 **「스코어 등록」** 으로 표시됩니다.

### 7.1 입력 안내 (도움말)

- 처음 들어오면 **스코어 입력 안내**가 한 번 자동으로 나옵니다. 이후에는 우측 상단 **도움말**에서 다시 볼 수 있습니다.
- 요약:
  1. 홀을 고른 뒤 **SCORE**, **PUTT**를 맞춥니다.
  2. **SCORE**는 **파 대비**(to par)입니다. 예: `0` = 파, `-1` = 버디, `+2` = 더블보기.
  3. **Fairway / Rough / Penalty / OB**를 필요에 따라 체크한 뒤 **`n`홀 저장**으로 저장합니다. 체크한 값은 FW 안착율 계산 등에 쓰입니다.
  4. 18홀을 모두 저장한 뒤 **스코어 확정**으로 마무리합니다.

### 7.2 홀 이동·코스 정보

- 상단의 **이전 홀 / 다음 홀** 버튼으로 9홀 단위(전반·후반) 안에서 이동합니다.
- 전반·후반이 모두 있으면 코스 이름이나 **(탭하여 후반 코스로 전환)** 안내를 눌러 **전반 ↔ 후반**을 바꿉니다.
- 홀마다 **Par**와 **거리(m)** 가 표시됩니다. 코스 안내 페이지가 등록된 골프장은 **코스 뷰**로 앱 안에서 열어 볼 수 있습니다.

### 7.3 저장과 확정

- 각 홀은 **`n`홀 저장**으로 저장합니다. 확정 전까지는 다시 수정할 수 있습니다.
- 저장 버튼 아래에 나의 **Out / In / Total** 합계가 파 대비 스코어와 함께 표시됩니다.
- **18홀을 모두 저장**해야 **스코어 확정** 버튼을 누를 수 있습니다.
- 확정하면 **「스코어 확정됨 (수정 불가)」** 상태가 되어 해당 라운드 스코어는 더 이상 바꿀 수 없습니다.
- **자동 확정은 없습니다.** 라운드 후 반드시 **「스코어 확정」** 을 직접 눌러 주세요. 확정된 라운드만 홈 통계와 MY 기록에 반영됩니다.

### 7.4 동반자 스코어 (스코어카드)

- 화면 아래 **스코어카드**에 참가자 전원의 홀별 스코어가 Par, Out/In 합계와 함께 표시됩니다. 버디 이하는 하트 아이콘으로 표시됩니다.
- **본인 스코어만** 입력·수정할 수 있습니다. 다른 사람의 타수는 대신 고칠 수 없습니다.

### 7.5 효과음

홀을 저장하면 결과에 맞는 음성 효과음이 나옵니다. (한국어 음성, 기기 소리 설정에 따름)

- 기본: 이글, 버디, 파, 보기, 더블보기, 트리플보기, 양파
- 3연속 파: **3연속 파 세이브** / 4연속: **아우디 파** / 5연속: **올림픽 파** / 6연속: **실력파 파**
- 연속 버디: **버디 버디**
- 파3·파4·파5 홀에서 연달아 버디: **사이클 버디**
- 효과음을 재생할 수 없으면 짧은 진동으로 저장을 알려 줍니다.

## 8. 거리 탭 (GPS 거리기록)

### 8.1 새 거리 기록

**경로:** 거리 탭 → 하단 **새 기록**

1. **클럽**(Driver, 3W~LW, Putter 등)을 선택합니다.
2. 샷을 하는 자리에서 **시작점**을 측정합니다. 처음에는 위치 권한을 허용해야 합니다.
3. 볼이 멈춘 곳으로 가서 **볼 위치**를 측정합니다. 두 지점 사이의 **측정 거리**가 표시됩니다. 필요하면 **다시 측정**합니다.
4. **저장**하면 기록됩니다. 오늘 진행 중인 라운드가 있으면 그 라운드와 골프장 이름이 함께 저장됩니다.

스마트폰 GPS는 몇 m 정도 오차가 있을 수 있으니 참고용으로 활용해 주세요. 각 측정값에는 GPS 정확도가 함께 표시됩니다.

### 8.2 기록 조회·삭제

- 목록에는 클럽, 거리, 날짜, 골프장이 표시됩니다. 아래로 당기면 새로고침됩니다.
- 상단에서 클럽을 고르고 **조회**를 누르면 해당 클럽 기록만 보이고 **Max / Min / Avg** 거리와 측정 횟수가 표시됩니다. **전체 기록 보기**로 되돌아갑니다.
- 기록을 **길게 누르면** 삭제할 수 있습니다.

## 9. 코스 탭

1. **권역**(수도권, 강원, 충청, 경상, 제주, 전라)을 선택하면 해당 지역 골프장이 나옵니다.
2. **검색창**에 이름·지역·주소 키워드를 넣으면 **전체 목록**에서 검색됩니다. (검색 시 권역 필터는 적용되지 않습니다.)
3. 골프장을 누르면 **코스 상세**로 이동합니다. 골프장명, 지역, 주소, 홈페이지 등이 표시됩니다.
4. 코스별로 **티(Black/Blue/White/Red)** 를 바꿔 가며 **홀별 Par·거리**를 볼 수 있습니다.
5. 찾는 골프장이 없으면 홈의 **코스추가 요청하기**를 이용하세요.

---

## 10. 코스 추가 요청

**경로:** 홈 →「코스추가 요청하기」

1. **골프장 이름**(필수), **지역**, **추가 설명**(코스 수, 홈페이지 등)을 입력하고 **요청 보내기**를 누릅니다.
2. 같은 창의 **내 요청 내역**에서 처리 상태(**접수 / 처리중 / 등록 완료 / 반려**)와 **관리자 답변**을 확인할 수 있습니다.

## 11. MY 탭

### 11.1 프로필 영역

- 닉네임, 이메일과 함께 핸디캡, 주소, 생년월일이 **입력된 경우** 표시됩니다.

### 11.2 나의 기록

- **확정된 라운드**만 표에 나옵니다.
- 열: 날짜, 골프장, 총타수, 버디, 파, 보기, FIR, GIR, PPR

### 11.3 설정

- **프로필 수정:** 닉네임, 주소, 생년월일(숫자만 입력, 예: 19900115), 핸디캡(0~54), 기본 티를 바꿀 수 있습니다.
- **알림 설정:** 현재 **준비 중**입니다.
- **언어:** 한국어, English, 日本語 중에서 고릅니다. 선택하면 바로 적용됩니다.

### 11.4 계정

- **로그아웃:** 확인 후 로그아웃됩니다.

## 12. 자주 묻는 질문 (FAQ)

**Q. 라운드 번호는 어디서 보나요?**  
A. 라운드를 만든 직후 안내창에 나오고, 라운드 탭 카드에도 스코어 확정 전까지 **#번호**로 표시됩니다.

**Q. 라운드 번호는 몇 자리인가요?**  
A. **6자리 숫자**입니다. 예전에 만든 라운드는 4자리일 수 있으며, 참여 화면에서 그대로 입력하면 됩니다.

**Q. 스코어를 잘못 넣었어요.**  
A. **스코어 확정 전**이면 해당 홀로 이동해 다시 입력하고 저장하면 됩니다. **확정 후**에는 앱에서 수정할 수 없습니다.

**Q. 라운드를 잘못 만들었어요.**  
A. 내가 만든 라운드이고 스코어 확정 전이면, 라운드 탭에서 카드를 **길게 눌러** 취소할 수 있습니다.

**Q. 홈 통계에 방금 친 라운드가 안 보여요.**  
A. 통계와 나의 기록은 **스코어를 확정한 라운드**만 반영합니다. 18홀 저장 후 **스코어 확정**을 눌러 주세요.

**Q. GPS 거리가 이상하게 나와요.**  
A. 하늘이 트인 곳에서 잠시 기다린 뒤 측정하면 정확도가 좋아집니다. 위치 권한이 꺼져 있으면 휴대폰 설정에서 허용해 주세요.

**Q. 효과음이 영어·일본어로도 나오나요?**  
A. 효과음은 한국어 음성만 있습니다. 화면 언어를 바꿔도 효과음은 그대로입니다.

**Q. 인터넷이 끊기면?**  
A. 스코어 저장과 라운드 생성에는 인터넷 연결이 필요합니다. 연결이 불안정하면 저장이 실패할 수 있으니, 연결을 확인한 뒤 다시 저장해 주세요.
