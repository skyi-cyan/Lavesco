# 라베스코(Lavesco) 개인정보 처리방침

**시행일:** 2026년 7월 3일  
**최종 수정일:** 2026년 7월 3일

(주)부루넷(이하 "회사")은 「개인정보 보호법」 등 관련 법령을 준수하며, 모바일 애플리케이션 **라베스코**(이하 "서비스") 이용자의 개인정보를 보호하기 위해 본 개인정보 처리방침을 수립·공개합니다.

---

## 1. 수집하는 개인정보 항목 및 수집 방법

회사는 서비스 제공을 위해 아래와 같은 개인정보를 수집합니다.

### 1.1 회원가입 및 계정 관리

| 구분 | 항목 | 수집 방법 |
|------|------|-----------|
| 필수 | 이메일 주소, 비밀번호(암호화 저장), 닉네임 | 회원가입 시 이용자 입력 |
| 필수 (소셜 로그인) | 이메일, 이름(표시 이름), 프로필 사진 URL, 로그인 제공자 정보(Google/Apple) | 소셜 로그인 시 해당 사업자로부터 제공 |
| 선택 | 주소, 생년월일 | 프로필 설정 시 이용자 입력 |
| 자동 생성 | Firebase 사용자 식별자(UID), 가입·수정 일시, 로그인 방식 | 서비스 이용 과정에서 자동 생성 |

### 1.2 골프 라운드 및 스코어

| 항목 | 설명 |
|------|------|
| 라운드 정보 | 골프장명, 코스명, 티타임, 라운드 상태 |
| 스코어 정보 | 홀별 타수, 퍼트, 페어웨이 등 스코어 데이터 |
| 참가자 정보 | 닉네임, 역할, 합계 스코어 등 |

라운드에 참여한 다른 이용자는 해당 라운드 범위에서 위 정보를 열람할 수 있습니다.

### 1.3 거리기록 기능

| 항목 | 설명 |
|------|------|
| 위치 정보 | GPS를 이용한 측정 시작·종료 지점의 위도·경도, 정확도 |
| 기록 정보 | 클럽 종류, 측정 거리, 기록 일시 |
| 연동 정보 (선택) | 연결된 라운드 ID, 골프장명, 라운드 날짜 |

위치 정보는 **거리기록 기능 사용 시에만** 수집되며, 이용자가 기능을 사용하지 않으면 수집되지 않습니다.

### 1.4 프로필 사진

| 항목 | 설명 |
|------|------|
| 프로필 이미지 | 이용자가 갤러리에서 선택한 사진 |

### 1.5 골프장 추가 요청

| 항목 | 설명 |
|------|------|
| 요청 정보 | 골프장명, 지역, 상세 내용 |
| 요청자 정보 | 사용자 ID, 이메일, 닉네임 |

### 1.6 서비스 이용 과정에서 자동 수집될 수 있는 정보

- 기기 정보(OS 종류, 앱 버전 등)
- 서비스 이용 기록, 오류 로그
- IP 주소, 접속 일시

위 정보는 Firebase(Google) 등 클라우드 인프라를 통해 자동으로 생성·수집될 수 있습니다.

### 1.7 앱 접근 권한

| 권한 | 목적 | 필수 여부 |
|------|------|-----------|
| 인터넷 | 서버 통신, 데이터 동기화 | 필수 |
| 위치(GPS) | 거리기록 기능 | 선택 (기능 사용 시) |
| 사진/갤러리 | 프로필 사진 선택 | 선택 (기능 사용 시) |
| 진동 | 앱 내 알림·피드백 | 선택 |

## 2. 개인정보의 수집·이용 목적

회사는 수집한 개인정보를 다음 목적에만 이용합니다.

1. **회원 식별 및 계정 관리** — 가입, 로그인, 본인 확인, 계정 정지·해지
2. **서비스 제공** — 골프 라운드 생성·참여, 스코어 기록·공유, 코스 조회, 거리기록
3. **프로필 관리** — 닉네임, 핸디캡, 기본 티, 프로필 사진 등 설정
4. **고객 지원** — 문의 응대, 공지 전달, 서비스 품질 개선
5. **골프장 정보 보완** — 이용자의 골프장 추가 요청 처리
6. **법령 준수** — 관련 법령에 따른 의무 이행

**마케팅 정보 수신 동의**는 선택 사항이며, 동의한 경우에 한해 프로모션·이벤트 안내에 활용할 수 있습니다. 동의하지 않아도 서비스 이용에 제한이 없습니다.

## 3. 개인정보의 보유 및 이용 기간

회사는 개인정보 수집·이용 목적이 달성되면 지체 없이 파기합니다. 다만, 관계 법령에 따라 보관이 필요한 경우 해당 기간 동안 보관합니다.

| 구분 | 보유 기간 |
|------|-----------|
| 회원 정보 | 회원 탈퇴 시까지 (탈퇴 후 30일 이내 파기) |
| 라운드·스코어·거리기록 | 회원 탈퇴 시까지, 또는 이용자가 삭제할 때까지 |
| 골프장 추가 요청 | 처리 완료 후 1년 (분쟁 대비) |
| 관련 법령에 따른 보관 | 전자상거래법, 통신비밀보호법 등 해당 법령이 정한 기간 |

## 4. 개인정보의 제3자 제공

회사는 이용자의 개인정보를 **원칙적으로 외부에 제공하지 않습니다.**  
다만, 아래의 경우에는 예외로 합니다.

- 이용자가 사전에 동의한 경우
- 법령에 근거하거나 수사·조사 기관의 적법한 요청이 있는 경우

**라운드 참여 시:** 동일 라운드에 참여한 다른 이용자에게 닉네임·스코어 등 라운드 관련 정보가 표시될 수 있습니다. 이는 서비스의 핵심 기능(스코어 공유)을 위한 것입니다.

## 5. 개인정보 처리 위탁 및 국외 이전

회사는 서비스 운영을 위해 아래와 같이 개인정보 처리를 위탁합니다.

| 수탁자 | 위탁 업무 | 보관·처리 위치 |
|--------|-----------|----------------|
| Google LLC (Firebase Authentication, Cloud Firestore, Cloud Storage) | 회원 인증, 데이터 저장·동기화, 프로필 사진 저장 | 미국 등 Google 데이터센터 (국외) |
| Google LLC (Google Sign-In) | Google 계정 로그인 | 미국 등 |
| Apple Inc. (Sign in with Apple) | Apple 계정 로그인 (iOS) | 미국 등 |

Firebase 이용에 따른 개인정보의 국외 이전은 서비스 제공에 필수적이며, Google의 개인정보 처리 정책이 적용됩니다.

- Google 개인정보 처리방침: https://policies.google.com/privacy
- Apple 개인정보 처리방침: https://www.apple.com/legal/privacy/

## 6. 이용자의 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

1. 개인정보 **열람·정정·삭제** 요청
2. 개인정보 **처리 정지** 요청
3. **회원 탈퇴** (앱 내 로그아웃·계정 삭제 기능 또는 문의를 통해 요청)

권리 행사는 아래 문의처로 연락해 주시면 지체 없이 조치하겠습니다.  
법령에 따라 열람·삭제 등이 제한될 수 있습니다.

## 7. 개인정보의 파기 절차 및 방법

1. **파기 절차:** 보유 기간 경과 또는 처리 목적 달성 후 내부 방침에 따라 파기 대상을 선정하고 승인 후 파기합니다.
2. **파기 방법**
   - 전자적 파일: 복구 불가능한 방법으로 영구 삭제
   - Firebase Storage에 저장된 프로필 사진: 해당 파일 삭제

## 8. 개인정보의 안전성 확보 조치

회사는 개인정보 보호를 위해 다음 조치를 취합니다.

- 비밀번호 등 민감 정보의 암호화 저장 (Firebase Authentication)
- Firebase 보안 규칙을 통한 접근 통제
- 개인정보 처리자에 대한 최소 권한 부여
- 클라우드 서비스 제공자의 보안 인증·암호화 전송(TLS) 활용

## 9. 아동의 개인정보

서비스는 **만 14세 미만 아동**을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 고의로 수집하지 않습니다.  
해당 사실이 확인되면 지체 없이 계정을 삭제하고 관련 정보를 파기합니다.
